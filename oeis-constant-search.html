OEIS Constant Search

Finds a decimal constant in the OEIS even if it is stored only as 2c, c/3, c², √c, 1/c, πc, e·c, exp(c), log(c) or ⌈c⌉−c. The search runs offline on your copy of the OEIS file stripped.

How the search works
  • The number of significant digits you type sets the search length. Trailing zeros count.
  • Each transform is evaluated with 64-digit arithmetic. The first significant digits of the result are rounded to that length and searched in the leading single-digit terms (0–9) of every sequence in stripped, at any term position.
  • With “tolerate rounding”, the typed constant may be rounded or truncated in its last digit, and so may the OEIS entry. Each transform is evaluated at both ends of that uncertainty interval. All digit strings in the interval are searched, plus the next higher one, because some OEIS entries are rounded. If more than three strings would be needed, one digit fewer is compared. The Digits column shows how many digits were compared. Matches that differ from the value computed from the typed digits are marked “rounding”.
  • Without “tolerate rounding”, only the rounded value is searched. For exp(c), log(c) and ⌈c⌉−c the input error is amplified, so the search uses one digit fewer for each factor of 10 of the amplification.
  • A result like 3.0000000000 is shown as a simple value and not searched.
